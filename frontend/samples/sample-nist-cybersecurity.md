# NIST cybersecurity basics

The NIST Cybersecurity Framework helps organizations manage cybersecurity risk. It provides a common language for understanding, assessing, prioritizing, and communicating cybersecurity activities.

## The five core functions

The framework groups cybersecurity outcomes into five functions: Identify, Protect, Detect, Respond, and Recover.

- Identify: understand the organization, assets, risks, and opportunities.
- Protect: use safeguards to limit or contain cybersecurity events.
- Detect: find and analyze possible cybersecurity incidents.
- Respond: take action after a detected incident.
- Recover: restore capabilities and improve from lessons learned.

Source: NIST Cybersecurity Framework — https://www.nist.gov/cyberframework
