# Bundled demo samples

These small fixtures make the public demo usable without relying on an external
download at click time.

| File | Format | Purpose | Reference |
|---|---|---|---|
| `embedded-images-tables.pdf` | PDF | Figure, table, and research text extraction | [Unstructured example documents](https://github.com/Unstructured-IO/unstructured-ingest/tree/main/example-docs) |
| `sample-project-brief.docx` | DOCX | Headings, paragraphs, and a delivery table | Hybrid RAG sample fixture |
| `sample-security-review.docx` | DOCX | Risk register and structured table extraction | Hybrid RAG sample fixture |
| `sample-nasa-earth.md` | Markdown | Earth science reference | [NASA Earth](https://science.nasa.gov/earth/) |
| `sample-nist-cybersecurity.md` | Markdown | Cybersecurity concepts and lists | [NIST Cybersecurity Framework](https://www.nist.gov/cyberframework) |

The DOCX fixtures are original project-generated examples. The PDF is retained
as a small parser fixture with its upstream reference link shown in the UI.
